# The Right-Hand Column

## Tabs

Click a tab at the top of the column to open or close its section:

| Tab | What's in it |
|---|---|
| **VFO** | Compact VFO A and B, with S meters. |
| **VFO SYNC** | VFO Sync, Rx Ant, VFO lock A / B, tune step, quick memory (Save / Restore) and the band stack. |
| **METERS** | An analog meter. OE3IDE's FTDX-5000 meter skin is offered on first run; right-click the meter to change it. |
| **BAND** | Band, mode and filter drop-downs, filter width and shift. |
| **RX** | Master AF, RX1 / RX2 AF, AGC gain, AGC, attenuator and squelch (SQL). |
| **TX** | Drive, Mic, Comp, VOX, the transmit profile, TX filter, and the MIC / COMP / VOX / DEXP / RX EQ / TX EQ / AV / TX FL buttons. |
| **PA** | The PA profile. |
| **EQ** | The equalizer buttons. |
| **KAINOS AUDIO** | Quick controls for [[Kainos Audio]]. |
| **FREEDV** | Quick controls for [[FreeDV RADE]]. |
| **MEMORY** | Your memories. |
| **SPOTS** | The latest spots. See [[Spots]]. |
| **KIWI** | KiwiSDR receivers. See [[KiwiSDR]]. |

## Arrange it your way

- **Drag** a section by its title in the column, or its tab at the top, to a new place. A gold marker shows where it will land.
- Or **right-click** a tab or title for **Move up**, **Move down**, **Move to the top / bottom** and **Reset the order**.

Your order is saved. New tabs in future versions are added at the end.

## Scrolling

When the open tabs don't all fit, a scroll bar appears on the right: drag it, or click above or below it. The **mouse wheel** anywhere over the column scrolls it. **Hold Ctrl** to use the wheel on a slider or list instead, so you never change a setting by accident while scrolling.
